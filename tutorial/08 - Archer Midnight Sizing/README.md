# 08 - Archer Midnight Sizing

This section applies the full `evtolpy` sizing workflow to the **Archer Midnight**, a real-world eVTOL aircraft. You will learn how to:

1. Load and inspect an Archer Midnight configuration (geometry, propulsion, battery, aerodynamics)
2. Run the MTOW iteration and examine the converged mass breakdown
3. Compare sizing results across different mission ranges (30, 45, 60 miles) and cruise altitudes (1,500 ft, 3,000 ft)
